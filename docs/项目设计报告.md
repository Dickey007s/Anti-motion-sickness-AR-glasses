# 基于 ESP32-S3 的车辆运动状态分析与实时视觉感官补偿防晕车眼镜

## 项目设计报告

---

## 1. 项目概述

### 1.1 项目背景

晕车（Motion Sickness）是一种常见的生理反应，其根本原因是视觉系统与前庭系统感知信息不一致。当乘客在车内阅读或低头看手机时，眼睛告知大脑"环境静止"，而内耳前庭器官却感知到车辆的加速、转弯和颠簸，这种感官冲突导致大脑产生混乱信号，引发头晕、恶心等症状。

### 1.2 核心原理：感觉冲突理论（Sensory Conflict Theory）

本项目基于感觉冲突理论提出创新解决方案：通过在用户视野中实时投射与车辆实际运动状态相匹配的视觉补偿信息，使视觉感知与前庭感知重新达成一致，从而消除或减轻感官冲突，达到防晕车效果。

### 1.3 作品名称

基于 ESP32 的车辆运动状态分析以及实时视觉感官补偿原理的防晕车眼镜

---

## 2. 系统总体架构

### 2.1 架构概览

系统采用简洁模块化设计，整体分为三层：

```
┌─────────────────────────────────────────────────────────┐
│                    视觉呈现层 (Display Layer)              │
│              彩色 IPS TFT 显示器 + 45° 折射镜片               │
├─────────────────────────────────────────────────────────┤
│                    算法处理层 (Algorithm Layer)            │
│              姿态解算 | 运动检测 | 补偿点阵生成             │
├─────────────────────────────────────────────────────────┤
│                    硬件感知层 (Hardware Layer)             │
│              BMI270 六轴传感器 | ESP32-S3 主控             │
└─────────────────────────────────────────────────────────┘
```

### 2.2 工作流程

1. **数据采集**：BMI270 以 100Hz 频率采集加速度数据
2. **姿态解算**：通过互补滤波解算当前姿态，分离出车辆纵向加速度
3. **运动检测**：判断车辆处于加速、减速或匀速状态
4. **补偿生成**：根据运动状态驱动点阵向相反方向运动
5. **视觉投射**：通过 45° 折射镜片将 TFT 画面投射至单眼视野中
6. **持续更新**：以 30Hz 刷新率循环运行

## 3. 硬件系统设计

### 3.1 主控芯片：ESP32-S3

| 参数 | 规格 |
|------|------|
| 架构 | Xtensa LX7 双核，最高 240MHz |
| 内存 | 512KB SRAM + 384KB ROM |
| 特性 | 支持浮点运算、Wi-Fi/BLE（本版未启用）|
| 适用原因 | 算力充足，片内资源丰富，开发便捷 |

**主控职责**：
- 传感器数据读取（I2C，400kHz）
- 姿态解算与运动检测
- 视觉补偿点阵生成
- TFT 显示驱动（SPI 接口）

### 3.2 运动传感器：Bosch BMI270

| 参数 | 加速度计 | 陀螺仪 |
|------|----------|--------|
| 量程 | ±2g/±4g/±8g/±16g | ±125°/s ~ ±2000°/s |
| 分辨率 | 16-bit | 16-bit |
| 接口 | I2C / SPI | I2C / SPI |
| 功耗 | 正常模式 ~130μA | 正常模式 ~3.5mA |

**传感器配置策略**：
- 工作模式：Normal Mode
- 加速度计 ODR：100Hz
- 陀螺仪 ODR：100Hz
- 接口：I2C（SDA: GPIO8, SCL: GPIO9），地址 0x68
- 量程：加速度计 ±4g，陀螺仪 ±500°/s

### 3.3 视觉显示模组

**方案**：1.47 英寸彩色 IPS TFT（172×320）+ 45° 折射镜片

- 驱动芯片：ST7789V3
- 接口：SPI（SCK: GPIO12, MOSI: GPIO11, CS: GPIO10, DC: GPIO13, RST: GPIO14）
- 显示内容：运动补偿点阵（纵向运动的点阵图案）

### 3.4 45° 折射光学模组

**光学原理**：

TFT 显示屏水平放置于镜片侧上方，光线以约 45° 入射角进入光学镜片。镜片采用光学级透明材料（PMMA 或光学玻璃），利用折射原理改变光路方向，使 TFT 虚像呈现在用户正视前方约 1.5~2 米处的视线中。

**设计要点**：

| 参数 | 设计值 | 说明 |
|------|--------|------|
| 入射角 | 45° | TFT 平面与镜片法线夹角 |
| 镜片倾角 | 45° | 相对于水平视线 |
| 虚像距离 | 1.5~2m | 与车窗外景物近似同焦，减少视觉疲劳 |
| 透光率 | ≥85% | 保证对真实环境的无障碍观察 |
| 适用眼别 | 单眼（左眼或右眼）| 单片式设计，仅覆盖一只眼睛 |

**为什么用折射而非反射**：
- 折射方案光路简洁，无分光损失，透光率更高
- 45° 放置的 TFT 与镜片结构紧凑，易于集成到镜架中
- 单层光学镜片即可实现，无需半透镀膜，成本更低

### 3.5 电源管理

| 组件 | 供电需求 | 备注 |
|------|----------|------|
| ESP32-S3 | 3.3V, 80-150mA | 正常工作时约 100mA（关闭射频节能）|
| BMI270 | 3.3V | I2C 直连 |

| 整机预估 | 3.7V, 120-180mA | 持续工作 |

- 充电：TP4056 线性充电芯片，Type-C 接口
- 稳压：AMS1117-3.3

### 4.1 软件架构

```
src/
├── main.cpp                  # 入口：初始化 + 主循环
├── config.h                  # 系统常量与引脚定义
├── drivers/
│   ├── bmi270_driver.cpp     # BMI270 I2C 驱动
│   └── tft_driver.cpp        # ST7789V3 SPI 驱动
├── algorithms/
│   ├── complementary_filter.cpp  # 互补滤波姿态解算
│   └── motion_compensator.cpp    # 运动检测与点阵补偿生成
└── utils/
    └── math_utils.cpp        # 基础数学运算
```

**设计原则**：初版以简洁易用为第一目标，不引入 FreeRTOS 多任务调度，采用单循环架构降低复杂度。

### 4.2 主循环流程

```
setup()
  ├── 初始化 I2C/SPI
  ├── 初始化 BMI270（100Hz，±4g，±500°/s）
  ├── 初始化 TFT（清屏，设置背光）
  └── 静止标定（2秒采样求零偏）

loop() @ 10ms 周期 (100Hz)
  ├── 读取 BMI270 加速度 + 陀螺仪
  ├── 互补滤波更新姿态（俯仰角、滚转角）
  ├── 提取世界坐标系纵向加速度（a_x_world）
  ├── 运动状态判断（加速 / 减速 / 匀速）
  ├── 根据运动状态更新点阵偏移量
  ├── 一阶平滑滤波
  └── TFT 绘制点阵帧
```

## 5. 核心算法设计

### 5.1 初版算法原则

初版算法追求**简洁、可验证、可演示**：
- 仅检测纵向运动（加速 / 减速 / 匀速）
- 仅生成纵向运动的点阵补偿（X 轴方向）
- 不涉及横向转弯、垂直颠簸等复杂场景
- 不涉及蓝牙、无线通信、OTA 等附加功能

### 5.2 传感器数据预处理

#### 5.2.1 零偏标定

上电后设备静止 2 秒，采集 200 组样本：

```
acc_offset = mean(acc_samples) - [0, 0, g]   // 加速度计零偏
gyr_offset = mean(gyr_samples)                // 陀螺仪零偏
```

后续所有读数减去零偏。

#### 5.2.2 低通滤波

对加速度进行一阶 IIR 低通滤波，抑制高频噪声：

```
a_filtered[n] = 0.3 * a_raw[n] + 0.7 * a_filtered[n-1]
```

### 5.3 姿态解算：互补滤波

融合加速度计（低频可信）与陀螺仪（高频可信）估计俯仰角：

```
pitch = 0.98 * (pitch + gyr_y * dt) + 0.02 * atan2(-acc_x, sqrt(acc_y^2 + acc_z^2))
roll  = 0.98 * (roll  + gyr_x * dt) + 0.02 * atan2(acc_y, acc_z)
```

其中 `dt = 0.01s`（100Hz），系数 0.98/0.02 为标准互补滤波参数。

> **为什么不用 EKF**：初版以简洁为原则，互补滤波在 100Hz 下足够满足车辆运动检测需求，代码量小、调试简单。

### 5.4 纵向加速度提取

将传感器坐标系的加速度转换到世界坐标系（以俯仰角为主）：

```
a_x_world = a_x * cos(pitch) + a_z * sin(pitch)   // 车辆前后方向加速度
```

`a_x_world` 正值为**加速**，负值为**减速**。

去除重力分量后，若传感器安装理想（X 轴严格水平向前），可简化为直接读取标定后的 `a_x`。

### 5.5 运动状态检测

```
if a_x_world > ACCEL_THRESHOLD:    // 默认 0.1g (~0.98 m/s²)
    state = ACCELERATING           // 车辆加速
elif a_x_world < -BRAKE_THRESHOLD: // 默认 -0.1g
    state = BRAKING                // 车辆减速/刹车
else:
    state = CRUISING               // 匀速或静止
```

### 5.6 视觉补偿点阵生成算法

**核心规则**：

| 车辆状态 | 视觉补偿效果 |
|----------|--------------|
| 加速 | 点阵**向后**运动（与用户感受的推背感方向相反，视觉暗示"外界在后退"）|
| 减速 | 点阵**向前**运动（视觉暗示"外界在靠近"）|
| 匀速 | 点阵静止在屏幕中心 |

**点阵实现**：

在 TFT 上绘制 3x5 或 4x6 的规则点阵，每帧整体平移：

```
// 目标偏移量：与加速度方向相反
if state == ACCELERATING:
    target_offset = -K * a_x_world        // K 为增益系数，向后为负
elif state == BRAKING:
    target_offset = -K * a_x_world        // 向前为正
else:
    target_offset = 0

// 一阶平滑，防止突变
offset = offset + alpha * (target_offset - offset)   // alpha = 0.15

// 限幅保护
offset = clamp(offset, -MAX_OFFSET, MAX_OFFSET)      // MAX_OFFSET = 12 px

// 绘制点阵：每点 x 坐标 += offset
for each dot in dot_grid:
    draw_dot(dot.x + offset, dot.y)
```

**参数默认值**：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| K | 20 px/g | 加速度到像素偏移的转换增益 |
| alpha | 0.15 | 平滑系数，约 100ms 时间常数 |
| MAX_OFFSET | 12 px | 最大偏移量，防止画面移出视野 |
| 点阵规格 | 4行 x 5列 | 规则排列的圆点 |
| 点间距 | 8 px | 水平/垂直间距 |

**视觉效果**：

- 车辆急加速时，用户看到点阵**整体向后流动**，大脑解读为"外界在后退"，与前庭感知的"向前加速"达成匹配
- 车辆刹车时，点阵**整体向前流动**，与前庭感知的"减速"匹配
- 匀速时点阵静止在视野中心，作为稳定的视觉锚点

## 6. 通信协议设计

本版仅涉及内部硬件通信，无外部无线通信。

### 6.1 BMI270 I2C 通信

- **接口**：I2C Fast Mode（400kHz）
- **设备地址**：0x68（SDO 接地）
- **初始化序列**：软复位 → 启用加速度计+陀螺仪 → 配置 ODR=100Hz、量程 ±4g/±500°/s
- **数据读取**：读取 `DATA_8` 寄存器组（12 字节：ACC_X/Y/Z + GYR_X/Y/Z）

### 6.2 TFT SPI 通信

- **接口**：SPI Mode 0，时钟 4MHz
- **命令序列**：初始化 → 设置对比度 → 设置显示方向 → 清屏 → 进入正常显示
- **帧刷新**：整帧写入（172×320 × 2字节 = 110KB 显存，RGB565 格式），30Hz 刷新率下 SPI 时钟需 ≥ 8MHz

### 7.1 显示内容规格

- **分辨率**：172×320（ST7789V3 驱动）
- **颜色**：RGB 彩色（65K 色，RGB565）
- **刷新率**：30Hz
- **亮度**：固定 80%（初版不调光）

### 7.2 显示元素

```
┌─────────────────────────────┐
│                             │
│    ·     ·     ·     ·      │   <- 第1行点阵
│                             │
│    ·     ·     ·     ·      │   <- 第2行点阵
│                             │
│    ·     ·     ·     ·      │   <- 第3行点阵
│                             │
│    ·     ·     ·     ·      │   <- 第4行点阵
│                             │
└─────────────────────────────┘
```

- 4 行 × 5 列规则点阵
- 点阵整体随车辆运动横向（水平方向）偏移
- 单片眼镜片，仅覆盖单眼，无需考虑双目视差

### 7.3 45° 折射光学设计

- **光路**：TFT 水平放置 → 光线以 45° 入射角进入镜片 → 折射后进入人眼
- **虚像距离**：约 1.5~2 米，与车窗外中远距离景物同焦平面
- **视场覆盖**：单眼中央视野约 10°×8°
- **透光率**：≥85%，镜片不镀膜或仅增透膜，不影响正常观察路况

## 10. 风险分析与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| BMI270 安装不水平导致纵向加速度提取不准 | 运动检测错误 | 增加上电标定流程，软件补偿安装倾角 |
| 点阵偏移过大引起视觉不适 | 用户体验差 | 严格限幅（MAX_OFFSET = 12px），增益渐进调试 |
| TFT 白天亮度不足 | 看不清补偿画面 | 选用高亮度 IPS 模组或增加遮光罩 |
| 陀螺仪漂移导致俯仰角缓慢偏移 | 长期精度下降 | 每次上电强制标定，运行中利用加速度计重力方向定期修正 |
| 单眼显示引起轻微复视感 | 初期不适 | 选用非主视眼（通常左眼）覆盖，让用户自然适应 |
